</objective>

1. Create src/scraping/vlr_events.py with VLREventScraper class:

   Purpose: Scrape VLR.gg event RESULTS pages to discover match URLs. VLR.gg organizes results under URLs like:
   - https://www.vlr.gg/event/matches/XXXX/event-name/?series_id=all
   - https://www.vlr.gg/event/XXXX/event-name/  (event overview)

   The scraper should:
   a. Accept a VLR.gg event URL (e.g., https://www.vlr.gg/event/matches/2094/champions-tour-2025-masters-bangkok/)
   b. Parse the results/matches page to extract all match URLs
   c. For each match URL, call Valoscribe's scrape_match() to get per-map VOD URLs and metadata
   d. Build VODRecord entries for each map

   Class structure:
   - __init__(self, rate_limit_seconds: float = 1.5):
     - self.session = requests.Session() with polite User-Agent header
     - self.rate_limit = rate_limit_seconds
     - self.last_request_time = 0.0
   - _rate_limit_delay(self) -> None: sleep if needed
   - _fetch_page(self, url: str) -> BeautifulSoup: GET with rate limiting, returns parsed HTML
   - discover_match_urls(self, event_url: str) -> list[str]:
     - Fetch the event matches/results page
     - Parse out match URLs (look for links containing /NUMBER/team1-vs-team2 pattern)
     - VLR.gg match result links are typically <a> tags within match result cards
     - CSS selectors to try: 'a.match-item' or links within 'div.wf-module-item' or similar
     - IMPORTANT: Selectors must be reverse-engineered from live pages. Include validation:
       log a warning if 0 matches found and suggest checking selectors.
     - Handle pagination if VLR.gg paginates results (check for "Load More" or page params)
     - Return list of full match URLs (prepend https://www.vlr.gg if relative)
   - discover_vods(self, event_url: str, manifest: ProcessingManifest, tournament_name: str) -> int:
     - Calls discover_match_urls to get all match URLs
     - For each match URL, calls Valoscribe's scrape_match() (import from valoscribe.scraper)
     - For each map in the match result, creates a VODRecord:
       - vod_id = f"{vlr_match_id}_map{map_number}" (extract match_id from URL path)
       - Skip if VOD URL is None (some maps may not have VOD links)
       - Skip if vod_id already in manifest (idempotent)
     - Adds all new records to manifest
     - Returns count of new VODs added
     - Logs progress: "Discovered X maps from Y matches"

   Standalone function:
   - discover_matches(event_url: str, manifest_path: Path, tournament_name: str, rate_limit: float = 1.5) -> int:
     - Convenience wrapper: creates scraper and manifest, calls discover_vods, returns count

   IMPORTANT: Import valoscribe.scraper.scrape_match at the top of the file. Since Valoscribe is installed as a package (or its src/ is on sys.path), this import should work. If import fails at runtime, the orchestrator (Plan 02) will handle it by adding Valoscribe to sys.path.

   Rate limiting: Default 1.5 seconds between requests (polite for VLR.gg). The Valoscribe scrape_match function makes its own requests, so space those out too.
