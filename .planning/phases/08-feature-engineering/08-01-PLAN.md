<feature>
  <name>Economy Reconstruction & Tier Classification</name>
  <files>src/features/__init__.py, src/features/economy.py, tests/features/__init__.py, tests/features/test_economy.py</files>
  <behavior>
    EconomyTracker takes a list of ValoscribeEvent objects for a single map and reconstructs per-team credits for each round.

    Economy rules (from CONTEXT.md - LOCKED decisions):
    - Pistol round (R1, R13): 800 credits per player (4000 per team)
    - Win bonus: 3000 credits per player (15000 per team)
    - Loss bonus escalation: 1900 -> 2400 -> 2900 (max, per player). Resets on win.
    - Spike plant bonus: 300 credits per player on attacking team (1500 per team), applied even on round loss
    - Kill reward: average ~200 per kill (simplified, per CONTEXT.md decision)
    - Overtime: flat 5000 credits per player (25000 per team) each round, no loss bonus

    Economy tier thresholds (per-player average credits):
    - pistol: rounds 1 and 13 (tagged separately, regardless of credits)
    - eco: 0-2500
    - light_buy: 2500-3500
    - half_buy: 3500-3900 (Claude's discretion from CONTEXT.md)
    - full_buy: 3900+

    Input: list[ValoscribeEvent] (all events for one map)
    Output: list[RoundEconomy] dataclass with fields:
      - round_number: int
      - team1_credits: int (estimated total team credits at round start)
      - team2_credits: int
      - team1_tier: str (eco/light_buy/half_buy/full_buy/pistol)
      - team2_tier: str
      - team1_loss_streak: int (consecutive losses entering this round)
      - team2_loss_streak: int

    Test cases:
    - Pistol round: both teams get 800*5=4000 -> tier="pistol"
    - Team wins R1: winner gets 4000+15000=19000 in R2 (tier=full_buy), loser gets 4000+1900*5=13500 (tier=full_buy after buying R1)
    - Actually, after pistol (players spend ~800, end with ~0), winner gets 3000*5=15000, loser gets 1900*5=9500. Per-player: winner=3000, loser=1900. But players don't start at 0 -- they have whatever's left. Simplified: track team totals.
    - 3-round loss streak: loss bonus = 1900, 2400, 2900 per player
    - Loss streak resets on win
    - Second pistol (R13): credits reset to 800 per player
    - Overtime (R25+): 5000 per player per round
    - Spike plant in a lost round: +300 per attacking player
    - Map with no spike plants: economy still tracks correctly
  </behavior>
  <implementation>
    Create EconomyTracker class that:
    1. Filters events to round_end and spike_plant types
    2. Determines teams from first round_end event (team names from winning_team field or metadata)
    3. Iterates through rounds chronologically
    4. Tracks credits using Valorant rules (reset at R1, R13, OT; apply win/loss/plant bonuses)
    5. Classifies tier based on per-player average (team_credits / 5)
    6. Returns list of RoundEconomy for each round

    Also create helper functions:
    - classify_economy_tier(per_player_credits: int, round_number: int) -> str
    - is_pistol_round(round_number: int) -> bool
    - is_overtime_round(round_number: int, max_regulation_rounds: int = 24) -> bool

    Handle edge cases:
    - Maximum credits cap: 9000 per player in regulation (not officially capped, but track spending assumption)
    - Standard loadout spending assumption: on full buy, team spends ~4000 per player (rifle + armor + abilities)
    - On eco, team spends ~500 per player
    - On light buy, ~2000 per player
    - Simplification per CONTEXT.md: use average kill reward (~200), ignore ability credits

    NOTE: Credit tracking is APPROXIMATE. The goal is tier classification, not exact credit values. Document assumptions in docstrings.
  </implementation>
</feature>
