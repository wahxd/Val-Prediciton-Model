    Create `src/features/extractors/match_features.py` for BO3/BO5 series prediction features.

    Per CONTEXT.md (LOCKED): No Elo ratings. Match-level features = per-map aggregation + series momentum.

    Function signature:
    ```python
    def extract_match_features(
        map_features_list: list[dict[str, Any]],  # Feature dicts from extract_map_features, ordered by map sequence
        series_format: str = "bo3",  # "bo3" or "bo5"
    ) -> dict[str, Any]:
    ```

    Match-level features (for predicting series winner from team1's perspective):

    **Series state features (computed BEFORE each map for prediction):**
    NOTE: For map-winner prediction, these features describe the series context the map is being played in. For match-winner prediction, these aggregate across all maps.

    - `maps_won_team1`: int (maps won so far)
    - `maps_won_team2`: int
    - `maps_played`: int (how many maps completed)
    - `series_score_differential`: int (team1_maps - team2_maps)
    - `series_format`: str (bo3 or bo5)

    **Series momentum features (per CONTEXT.md LOCKED decisions):**
    - `avg_map_score_diff`: float (mean score_differential across completed maps)
    - `maps_to_overtime_count`: int (how many completed maps went to OT)
    - `maps_to_overtime_pct`: float (% of completed maps that went to OT)
    - `comeback_indicator`: bool (team was behind in series but is now tied or leading)
    - `prev_map_score_diff`: float | None (score differential of previous map, None for first map)
    - `prev_map_went_ot`: bool | None (did previous map go to OT)
    - `series_momentum`: int (+1 for each consecutive map win by team1, -1 for team2, 0 at start)

    **Aggregated map statistics:**
    - `avg_first_blood_rate`: float (mean first blood rate across maps)
    - `avg_attack_win_rate`: float (mean attack win rate across maps)
    - `avg_defense_win_rate`: float (mean defense win rate across maps)
    - `pistol_round_win_pct`: float (total pistol rounds won / total pistol rounds played across maps)

    Edge cases:
    - First map of series: momentum features are 0/None (no prior maps)
    - BO1 (single map): all series features are default/zero
    - Series with only 1 map completed: limited momentum data

    Create tests:
    - BO3 where team1 wins 2-1 (comeback scenario)
    - BO3 where team1 wins 2-0 (dominant)
    - First map context (no prior maps)
    - Series with OT maps

    Create `src/features/pipeline.py` -- the main entry point that ties together all feature extraction components.

    Classes and functions:

    ```python
    class FeaturePipeline:
        """End-to-end feature extraction from Valoscribe data to model-ready DataFrame."""

        def __init__(self, feature_set: str = "core", registry: FeatureRegistry | None = None):
            """
            Args:
                feature_set: Name of feature set from registry (determines output columns)
                registry: Optional pre-loaded registry (default: loads from default YAML)
            """

        def extract_map_dataset(
            self,
            map_data_list: list[MapData],
        ) -> pd.DataFrame:
            """Extract features from multiple maps into a DataFrame.

            Args:
                map_data_list: List of loaded MapData objects

            Returns:
                DataFrame where each row is one map (from team1's perspective),
                columns are features from the requested feature set + map_id + map_winner
            """

        def extract_match_dataset(
            self,
            series_maps: dict[str, list[MapData]],  # series_id -> ordered list of maps
            series_formats: dict[str, str] | None = None,  # series_id -> "bo3"/"bo5"
        ) -> pd.DataFrame:
            """Extract features for match/series prediction.

            Args:
                series_maps: Maps grouped by series, ordered by play sequence
                series_formats: Optional format specification per series

            Returns:
                DataFrame where each row is one map within a series,
                includes both map-level and match-level features
            """
    ```

    Implementation:
    1. For each map: call extract_map_features() to get raw feature dict
    2. Collect into list of dicts
    3. Convert to DataFrame
    4. Filter columns to only those in the requested feature set (from registry)
    5. Always include: map_id, map_winner (metadata columns, not features)
    6. For match dataset: also call extract_match_features() and merge series features

    Important: The pipeline does NOT do any train/test splitting. That is Phase 9's responsibility.
    The pipeline produces the full feature DataFrame. Phase 9 will use TimeSeriesSplit on it.

    Handle errors gracefully:
    - Maps with extraction errors: log warning, skip map, continue
    - Features that can't be computed (None): fill with NaN in DataFrame
    - Missing feature set name: raise ValueError with available sets
