  <name>Task 1: Implement BO3/BO5 series probability with momentum adjustment</name>
  <files>
    src/modeling/series.py
  </files>
  <action>
    Create src/modeling/series.py with the following functions:

    1. `series_win_probability(p_map, series_format, series_score=(0,0), momentum=0.03) -> float`:
       - Dispatcher that calls BO3 or BO5 based on series_format ("bo3" or "bo5")
       - Returns P(Team A wins series) from current score state

    2. `_series_win_probability_recursive(p_map, wins_needed, a_wins, b_wins, momentum, max_prob=0.95, min_prob=0.05) -> float`:
       - Recursive implementation that tracks all possible score paths
       - Terminal states: a_wins == wins_needed -> 1.0, b_wins == wins_needed -> 0.0
       - Momentum adjustment: p_adjusted = p_map + momentum * (a_wins - b_wins), clamped to [min_prob, max_prob]
       - For BO3: wins_needed=2, for BO5: wins_needed=3

    3. `compute_series_probabilities(map_predictions: list[float], series_format: str, momentum: float = 0.03) -> dict`:
       - Takes list of per-map win probabilities for Team A
       - Computes overall series win probability using average of per-map probabilities
       - Also computes conditional probabilities at each score state:
         - After map 1 (1-0 or 0-1), after map 2 (2-0, 1-1, 0-2), etc.
       - Returns dict with: overall_series_prob, per_map_probs, conditional_probs (at each observed score state), series_format

    4. `validate_series_calibration(y_true_series: list[int], y_pred_series: list[float], n_bins: int = 5) -> dict`:
       - Similar to validate_calibration from experiment.py but for series outcomes
       - Uses fewer bins (5 instead of 10) because sample size is small (~20-30 series)
       - Reports: bins, passes (with relaxed 60% threshold), max_deviation, total_series
       - Includes caveat text: "Series-level calibration is directional (n={total_series}); insufficient for statistical confidence"

    Design principles:
    - Map veto/pick data NOT available (CONTEXT decision) -- no map comfort adjustment
    - Momentum is a simple score modifier, NOT feature-based from completed maps (CONTEXT decision)
    - Probabilities clamped to [0.05, 0.95] to avoid degenerate extremes
    - Start momentum at 0.03 (Claude's discretion within 0.02-0.05 range from CONTEXT)
