  <name>Task 1: Implement cross-tournament validation and recency weighting</name>
  <files>

  <action>
    Create src/modeling/cross_tournament.py with the following:

    1. `leave_one_tournament_out_cv(X, y, tournament_ids, model_factory, feature_names=None) -> dict`:
       - Uses LeaveOneGroupOut with tournament_ids as groups
       - For each fold: train on all-but-one tournament, test on held-out tournament
       - Compute per-tournament log_loss, accuracy, n_samples
       - If feature_names provided: compute SHAP importance per tournament fold (for stability analysis)
       - Returns dict with:
         - per_tournament_results: list of {tournament, log_loss, accuracy, n_samples, shap_importance (optional)}
         - overall_log_loss: computed on concatenated predictions
         - accuracy_range: max - min accuracy across tournaments
         - meta_shift_detected: bool (accuracy_range > 0.10 per CONTEXT)
         - worst_tournament: name and metrics of worst-performing fold

    2. `compute_recency_weights(tournament_ids, tournament_order: list[str]) -> np.ndarray`:
       - tournament_order: list of tournament names from oldest to newest
       - Assigns weights: most recent = 1.0, one back = 0.7, two back = 0.5, three+ back = 0.3
       - For <= 5 tournaments: use fixed weights per CONTEXT
       - Returns per-sample weight array (each sample gets its tournament's weight)

    3. `compare_training_strategies(X, y, groups, tournament_ids, tournament_order, model_factory, feature_names=None) -> dict`:
       - Runs three variants on the same temporal CV:
         a. **Champions-only**: Train only on samples from first tournament in tournament_order
         b. **Mixed (all pooled)**: Train on all samples equally weighted
         c. **Recency-weighted**: Train on all samples with tournament-level recency weights (using sample_weight parameter in model.fit())
       - Each variant evaluated using the same test folds (e.g., most recent tournament as holdout)
       - Returns dict with:
         - champions_only: {log_loss, accuracy}
         - mixed: {log_loss, accuracy}
         - recency_weighted: {log_loss, accuracy}
         - best_strategy: name of strategy with lowest log_loss
         - comparison_table: formatted comparison

    4. `generate_cross_tournament_report(loto_results, strategy_comparison, stability_results=None) -> dict`:
       - Structured per CONTEXT cross-tournament diagnostic:
         1. **Statistical reality check**: Is accuracy drop beyond CV noise? Confidence intervals
         2. **Feature shift diagnosis**: SHAP comparison via compare_feature_importance_across_groups (from thesis_validation.py)
         3. **Thesis validation**: Does hierarchy hold across tournaments?
         4. **Trading implication**: Stable features (trustworthy) vs meta-dependent (signal may expire), recommended retrain frequency
       - If no meta shift detected (accuracy_range < 10pp): report says "No meta shift detected, model generalizes well"
       - Returns JSON-serializable dict

    Design per CONTEXT:
    - Mixed temporal training is DEFAULT (pool all tournaments by date, walk-forward)
    - Leave-one-tournament-out is DIAGNOSTIC only (not primary validation)
    - Tournament-level weights for recency (1.0, 0.7, 0.5, 0.3) -- meta shifts at tournament boundaries
    - Evolve to exponential decay when >5 tournaments (future-proof but implement fixed weights now)
    - >10pp accuracy drop triggers structured investigation
    - Report covers: statistical check, feature shift, thesis validation, trading implication
