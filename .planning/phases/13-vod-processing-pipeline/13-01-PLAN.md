    1. **Create `src/pipeline/quality_validator.py`:**

    ```python
    """Quality validation for processed Valoscribe output.

    Bridges Valoscribe output files (events.jsonl, metadata.json) to the
    quality scoring system (src/data/quality.py). Returns a metrics dict
    suitable for storage in VODRecord.quality_metrics.
    """
    ```

    **Function: validate_map_output(output_dir: Path, map_id: str) -> dict**
    - Loads `events.jsonl` from output_dir, parsing each line via `parse_event()` from `src/data/schemas.py`
    - Loads `metadata.json` from output_dir as `MapMetadata`
    - Calls `score_map_quality(events, metadata, map_id)` from `src/data/quality.py`
    - Returns a dict with:
      ```python
      {
          "overall_score": float,  # 0.0-1.0
          "tier": str,  # "high", "medium", "low"
          "flagged_for_review": bool,
          "checks": {
              check.name: {
                  "score": check.score,
                  "issues": check.issues,
                  "warnings": check.warnings,
              }
              for check in quality_score.checks
          },
          "total_events": int,  # len(events)
          "total_rounds": int,  # max round number
          "cross_check_disagreements": list[str],
          "all_issues": list[str],
          "all_warnings": list[str],
      }
      ```
    - If events.jsonl is missing or empty, returns a dict with overall_score=0.0, tier="low", flagged_for_review=True, and an issue: "No events found in output"
    - If metadata.json is missing, still runs quality checks with metadata=None (quality checks handle None metadata)

    **Class: QualityValidator**
    Simple wrapper for batch use:
    ```python
    class QualityValidator:
        """Validates quality of processed Valoscribe output."""

        def __init__(self, valoscribe_output_base: Path):
            """
            Args:
                valoscribe_output_base: Base directory containing processed map dirs
                    (e.g., D:/Git/valoscribe/data/processed/)
            """
            self.output_base = valoscribe_output_base

        def validate(self, map_id: str) -> dict:
            """Validate a single map's output quality.

            Args:
                map_id: Directory name under output_base

            Returns:
                Quality metrics dict for storage in VODRecord.quality_metrics
            """
            output_dir = self.output_base / map_id
            return validate_map_output(output_dir, map_id)
    ```
