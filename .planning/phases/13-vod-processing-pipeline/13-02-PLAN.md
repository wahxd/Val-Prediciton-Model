    **Class: BatchProcessor**

    Constructor:

    ```python
    def __init__(
    ```

    **Method: _get_processing_queue(batch_size: int, retry_failed: bool = False) -> list[VODRecord]**
    - Get pending VODs, ordered by tournament then by vod_id (tournament order = complete one tournament before starting next)
    - If retry_failed is True, also include records with status "download_failed" or "processing_failed" (reset their status to "pending" first)
    - Limit to batch_size records
    - Return ordered list
    - Implementation: Sort records by (tournament, vod_id) to group by tournament. Use `manifest.get_by_status("pending")` as base. If retry_failed, also add `manifest.get_by_status("download_failed") + manifest.get_by_status("processing_failed")`.

    **Method: _cleanup_partial_output(record: VODRecord) -> None**
    - Called when processing fails to clean up incomplete Valoscribe output
    - Check for output directory at `config.output_dir / record.vod_id`
    - If directory exists, delete events.jsonl, frames.csv, metadata.json inside it
    - Then remove the directory itself if empty
    - Log what was cleaned up
    - Catch and log any cleanup errors (don't propagate -- cleanup is best-effort)

    **Method: process_batch(batch_size: int | None = None, retry_failed: bool = False) -> dict**
    Main processing loop:
    ```python
    batch_size = batch_size or self.config.batch_size
    queue = self._get_processing_queue(batch_size, retry_failed)

    if not queue:
        self.log.info("no_vods_to_process")
        return self._generate_batch_summary([], 0, 0, 0)

    consecutive_failures = 0
    processed = 0
    succeeded = 0
    failed = 0

    # Track current tournament for progress display
    current_tournament = None

    with tqdm(total=len(queue), desc="Processing VODs", unit="vod") as pbar:
        for record in queue:
            # Log tournament transitions
            if record.tournament != current_tournament:
                current_tournament = record.tournament
                self.log.info("tournament_start", tournament=current_tournament)
                pbar.set_postfix(tournament=current_tournament[:30])

            # Update progress bar description
            teams_str = f"{record.teams[0]} vs {record.teams[1]}" if len(record.teams) >= 2 else str(record.teams)
            pbar.set_description(f"{record.map_name}: {teams_str}"[:50])

            # Process the VOD
            success = self.orchestrator.process_single_vod(record)

            if success:
                consecutive_failures = 0
                succeeded += 1

                # Run quality validation
                try:
                    metrics = self.validator.validate(record.vod_id)
                    self.manifest.update_status(
                        record.vod_id,
                        "complete",  # Keep status as complete (already set by process_single_vod)
                        quality_metrics=metrics
                    )
                    self.log.info(
                        "quality_validated",
                        vod_id=record.vod_id,
                        score=metrics.get("overall_score", 0),
                        tier=metrics.get("tier", "unknown")
                    )
                except Exception as e:
                    self.log.warning(
                        "quality_validation_failed",
                        vod_id=record.vod_id,
                        error=str(e)
                    )
                    # Quality validation failure is non-fatal -- VOD is still "complete"
            else:
                consecutive_failures += 1
                failed += 1

                # Clean up partial output
                self._cleanup_partial_output(record)

                # Refine failure status based on current manifest status
                # process_single_vod already sets "failed" -- update to granular status
                current_record = self.manifest.records.get(record.vod_id)
                if current_record and current_record.status == "failed":
                    # Determine if it was a download or processing failure
                    # by checking if status was "downloading" vs "processing" when error occurred
                    error_msg = current_record.error_message or ""
                    if "download" in error_msg.lower() or current_record.started_at and not any(
                        r.status == "processing" for r in [current_record]
                    ):
                        # Actually, simpler: check what the VODOrchestrator last set
                        # Since process_single_vod catches all exceptions, we look at error_message
                        pass  # Keep as "failed" -- orchestrator already set the right status

                # Circuit breaker check
                if consecutive_failures >= self.config.circuit_breaker_threshold:
                    self.log.error(
                        "circuit_breaker_tripped",
                        consecutive_failures=consecutive_failures,
                        threshold=self.config.circuit_breaker_threshold,
                        remaining=len(queue) - processed - 1
                    )
                    pbar.set_description("STOPPED: Circuit breaker tripped")
                    break

            processed += 1
            pbar.update(1)

    return self._generate_batch_summary(queue, processed, succeeded, failed)
    ```

    **IMPORTANT design note on failure status granularity:** Instead of trying to detect download vs processing failure in BatchProcessor (which would be fragile), update VODOrchestrator.process_single_vod() to set the granular status directly. See Task 2 for orchestrator updates.

    **Method: _generate_batch_summary(queue, processed, succeeded, failed) -> dict**
    Returns:
    ```python
    {
        "batch_size": len(queue),
        "processed": processed,
        "succeeded": succeeded,
        "failed": failed,
        "circuit_breaker_tripped": failed > 0 and consecutive_failures >= self.config.circuit_breaker_threshold,
        "quality_distribution": {
            "high": count of complete records with quality_metrics.tier == "high",
            "medium": count with tier == "medium",
            "low": count with tier == "low",
            "unvalidated": count with quality_metrics is None,
        },
        "manifest_summary": self.manifest.get_summary(),
    }
    ```

    ```
    Quality Distribution:
      High: 12 (66.7%)

      Low: 1 (5.6%)

    Manifest Status:
      Pending: 149
      Complete: 18
      Download Failed: 1
      Processing Failed: 1

    Circuit Breaker: OK (0 consecutive failures)
    ```

    Update VODOrchestrator.process_single_vod() in `src/pipeline/orchestrator.py`:

    1. **Granular failure statuses:**
    Currently, all failures set status to "failed". Update to use granular statuses:
    - In the download step (after "downloading" status is set): catch exceptions and set status to "download_failed" instead of "failed"
    - In the processing step (after "processing" status is set): catch exceptions and set status to "processing_failed" instead of "failed"
    - TimeoutExpired during processing: set status to "processing_failed"

    Specifically, restructure the exception handling:
    ```python
    def process_single_vod(self, record: VODRecord) -> bool:
        start_time = datetime.now(timezone.utc)
        vod_file = None
        download_phase = True  # Track which phase we're in

        try:
            # ... existing download steps ...
            # After download completes successfully:
            download_phase = False

            # ... existing processing steps ...
            return True

        except subprocess.TimeoutExpired as e:
            error_msg = f"Processing timeout after {self.config.processing_timeout_seconds}s"
            status = "download_failed" if download_phase else "processing_failed"
            self.manifest.update_status(
                record.vod_id, status,
                error_message=error_msg,
                retry_count=record.retry_count + 1
            )
            return False

        except Exception as e:
            error_msg = str(e)
            status = "download_failed" if download_phase else "processing_failed"
            self.manifest.update_status(
                record.vod_id, status,
                error_message=error_msg,
                retry_count=record.retry_count + 1
            )
            return False

        finally:
            # ... existing cleanup (unchanged) ...
    ```

    2. **Use download_timeout_seconds from config:**
    In the download step, pass `timeout=self.config.download_timeout_seconds` to the download command:
    ```python
    self._run_valoscribe_cmd([
        "download",
        record.youtube_url,
        "--output", str(self.config.download_dir),
        "--overwrite"
    ], timeout=self.config.download_timeout_seconds)
    ```

    The existing processing step already uses `self.config.processing_timeout_seconds`.

    Do NOT change the method signature or return type. Only change the status strings and add the download timeout.
