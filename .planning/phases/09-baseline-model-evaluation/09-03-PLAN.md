<task type="auto">
  <name>Task 2: End-to-end experiment runner with baseline comparisons</name>
  <files>src/modeling/experiment.py, tests/modeling/test_experiment.py</files>
  <action>
Create `src/modeling/experiment.py` that ties all modeling components together:

**1. `compute_naive_baselines(y_true) -> dict`**
- Compute naive prior baseline: always predict 0.5
  - log_loss = log_loss(y_true, [0.5] * len(y_true))  # Should be ~0.693
  - brier_score and accuracy similarly
- Compute majority class baseline: always predict the majority class probability
  - majority_prob = max(y_true.mean(), 1 - y_true.mean())
  - log_loss, brier_score, accuracy
- Return dict with "naive_prior" and "majority_class" sub-dicts, each containing "log_loss", "brier_score", "accuracy"

**2. `validate_calibration(y_true, y_pred_proba, n_bins=10, tolerance=0.10) -> dict`**
- Compute calibration curve: `calibration_curve(y_true, y_pred_proba, n_bins=n_bins, strategy='uniform')`
- For each bin, check: |fraction_of_positives - mean_predicted_value| <= tolerance
- Return dict with:
  - "bins": list of dicts with "predicted", "observed", "deviation", "within_tolerance" per bin
  - "bins_within_tolerance": count
  - "total_bins": count (bins with samples)
  - "tolerance": the tolerance value
  - "passes": True if >= 70% of bins are within tolerance (relaxed for small n)
  - "max_deviation": largest absolute deviation across bins

**3. `run_experiment(config: ExperimentConfig, X, y, groups, feature_names) -> dict`**
This is the unified entry point that orchestrates a complete experiment:
- Create BaselineTrainer from config.model
- Run `temporal_cross_validate()` using trainer.model_factory
- Compute naive baselines via `compute_naive_baselines(y)`
- Train final model on full dataset (for SHAP analysis and serialization)
- Compute SHAP importance via `compute_shap_importance()`
- Validate game mechanics dominance
- Validate calibration from CV predictions
- Generate evaluation report via `generate_evaluation_report()`
- Serialize model to JSON via `serialize_model_to_json()`
- Generate SHAP plot in experiment directory
- Return comprehensive results dict:
  ```python
  {
      "experiment_id": config.experiment_id,
      "cv_results": {... from temporal_cross_validate ...},
      "naive_baselines": {... from compute_naive_baselines ...},
      "beats_naive_prior": bool,  # True if model log_loss < naive_prior log_loss
      "beats_majority_class": bool,
      "shap_analysis": {... from compute_shap_importance ...},
      "game_mechanics_validation": {... from validate_game_mechanics_dominance ...},
      "calibration_validation": {... from validate_calibration ...},
      "experiment_dir": Path,  # where outputs were saved
  }
  ```
