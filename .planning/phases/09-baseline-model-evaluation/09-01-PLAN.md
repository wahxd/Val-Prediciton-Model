<task type="auto">
  <name>Task 2: Evaluation framework with temporal CV and report generation</name>
  <files>src/modeling/evaluation.py, tests/modeling/test_evaluation.py</files>
  <action>
Create `src/modeling/evaluation.py` with three main functions:

**1. `compute_metrics(y_true, y_pred_proba) -> dict`**
- Compute log_loss using `sklearn.metrics.log_loss`
- Compute brier_score using `sklearn.metrics.brier_score_loss`
- Compute accuracy using `sklearn.metrics.accuracy_score` (threshold at 0.5)
- Return dict with keys: "log_loss", "brier_score", "accuracy"
- Handle edge cases: single-class fold (return NaN for log_loss)

**2. `temporal_cross_validate(X, y, groups, model_factory, calibration_method="sigmoid", calibration_cv=5) -> dict`**
- `model_factory` is a callable that returns a fresh sklearn estimator (avoids reusing fitted model)
- Use `sklearn.model_selection.LeaveOneGroupOut` with `groups` parameter (series_id)
- For each fold:
  - Create fresh model from factory
  - Wrap in `CalibratedClassifierCV(estimator=model, method=calibration_method, cv=calibration_cv, ensemble=True)`
  - Fit on train split, predict_proba on test split
  - Compute fold metrics via `compute_metrics()`
  - Store fold predictions and true labels
- After all folds:
  - Aggregate fold metrics (mean and std)
  - Concatenate all predictions for overall metrics
  - Return dict with: "fold_metrics" (list), "aggregate_metrics" (mean/std), "overall_metrics" (computed on concatenated predictions), "all_y_true" (numpy array), "all_y_pred" (numpy array), "n_folds" (int)
- **Important edge case**: If a fold has only one class in training data (e.g., all wins), skip that fold and log a warning. CalibratedClassifierCV requires both classes in training.
- **Important edge case**: If calibration_cv is larger than samples in a class within training split, reduce it automatically (min of calibration_cv and min class count).

**3. `generate_evaluation_report(experiment_config, cv_results, output_dir) -> Path`**
- Create experiment directory: `output_dir / experiment_config.experiment_id`
- Save `config.json`: the experiment config as JSON
- Save `metrics.json`: aggregate metrics + overall metrics + fold count + per-fold metrics
- Generate `calibration_curve.png` using `sklearn.calibration.calibration_curve`:
  - Plot perfect calibration line (dashed diagonal)
  - Plot model calibration curve with markers
  - Use n_bins=10, strategy='uniform'
  - Title: "Calibration Curve (Reliability Diagram)"
  - X-axis: "Mean predicted probability"
  - Y-axis: "Fraction of positives"
  - Grid, legend
  - Save at 150 DPI
- Generate `prediction_distribution.png`:
  - Histogram of predicted probabilities
  - Vertical line at 0.5
  - Title: "Prediction Distribution"
- Return path to experiment directory
- Use `matplotlib.pyplot` with `plt.close(fig)` after each plot to avoid memory leaks

Use synthetic data for tests: Create a small dataset with 3-4 groups (series), ~20-30 samples, 2 features. Use `sklearn.datasets.make_classification` or manual arrays. Do NOT depend on Valoscribe data.
