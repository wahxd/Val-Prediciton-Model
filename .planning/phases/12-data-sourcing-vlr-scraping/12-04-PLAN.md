    1. Create `src/scraping/tournament_scraper.py`:

    **Class: TournamentScraper**

    Constructor:
    ```python
    def __init__(
        self,
        manifest: ProcessingManifest,
        youtube_api_key: str | None = None,
        cache_dir: str | Path = "data/cache/vlr_pages",
        rate_per_second: float = 1.0,
    )
    ```
    - Stores manifest reference
    - Creates YouTubeVODFinder (with api_key or from env)
    - Stores cache_dir and rate for creating VLREventScraper later
    - Creates TeamNormalizer (shared instance)
    - Initializes stats tracking dict: {tournament: {maps_found, maps_with_vod, maps_skipped, skip_reasons: []}}

    **Method: async scrape_tournament(event_url: str, tournament_name: str) -> dict**
    End-to-end scraping for one tournament:
    1. Create VLREventScraper (async context) with cache_dir and rate
    2. Discover match URLs from event page
    3. For each match:
       a. Scrape match page via VLREventScraper.scrape_match(match_url) -> parsed match data
       b. For each map in match:
          - If map has VLR.gg VOD URL, validate via YouTubeVODFinder.validate_video()
          - If no VLR URL or VLR URL invalid, search via YouTubeVODFinder.find_map_vod()
          - If no accessible VOD found, SKIP this map (log reason, increment stats)
          - If accessible VOD found, create VODRecord with all metadata:
            * vod_id: "{vlr_match_id}_map{N}"
            * youtube_url: validated URL
            * vlr_match_url: match page URL
            * teams: normalized team names
            * map_name, map_number, tournament, date
            * player_stats, agent_compositions, player_vlr_ids (from VLRMatchScraper)
            * match_score, match_outcome
            * status: "pending"
          - Check idempotency: skip if vod_id already in manifest.records
       c. YouTubeVODFinder is sync; call via asyncio.to_thread() to avoid blocking event loop
       d. Catch QuotaExhaustedError: log warning, stop YouTube searches, continue with VLR URLs only
    4. Bulk add all new VODRecords to manifest via manifest.add_vods()
    5. Return stats dict for this tournament

    **Method: async scrape_all(tournaments: list[dict]) -> dict**
    - tournaments is list of {"event_url": str, "name": str}
    - Scrapes each tournament sequentially (different event pages)
    - After each tournament, log progress and YouTube quota remaining
    - If total maps with VODs < 80 after all tournaments, log warning suggesting adding another tournament
    - Returns combined stats dict

    **Method: generate_report(stats: dict) -> str**
    - Generates human-readable summary report:
      ```
      == Scraping Report ==
      Tournament: Masters Bangkok 2024
        Matches found: 25
        Maps found: 62
        Maps with accessible VOD: 48
        Maps skipped: 14
          - No YouTube VOD found: 8
          - VOD inaccessible (private/deleted): 4
          - Already in manifest: 2

      Tournament: VCT Americas 2024
        ...

      == Totals ==
      Total maps with VODs: 88
      YouTube API quota used: 6200/10000
      Manifest records: 88 pending
      ```
    - Also saves report to `data/processing/scraping_report.txt`
