  <action>
    Create `src/scraping/youtube_vod_finder.py`:

    **Class: YouTubeVODFinder**

    Constructor:
    ```python
    def __init__(self, api_key: str | None = None):
    ```
    - If api_key is None, reads from `os.environ["YOUTUBE_API_KEY"]` (raise ValueError if not set)
    - Creates YouTube API service via `build('youtube', 'v3', developerKey=api_key)`
    - Initializes quota_used counter (int, starts at 0)
    - QUOTA_LIMIT = 10000 (daily limit)
    - Uses structlog for logging

    **Method: find_map_vod(teams, tournament, map_name, date=None, map_number=None) -> str | None**
    - Constructs search query: `"{teams[0]} vs {teams[1]} {map_name} {tournament}"`
    - If map_number provided, append "Map {map_number}" to query
    - If date provided (YYYY-MM-DD), use publishedAfter parameter (date - 7 days) and publishedBefore (date + 30 days) for filtering
    - Calls `youtube.search().list(q=query, part="id,snippet", type="video", maxResults=5, videoDuration="long")`
      - videoDuration="long" filters for >20min videos (map VODs are 30-60min)
    - Costs 100 quota units per search.list call. Increment quota_used by 100.
    - Check quota BEFORE making the call. If quota_used + 100 > QUOTA_LIMIT, raise QuotaExhaustedError.
    - For each result video_id, call validate_video(video_id)
    - Return first accessible video URL, or None if none found
    - Log: "YouTube search: '{query}' -> {N} results, {accessible_count} accessible"

    **Method: validate_video(video_id: str) -> bool**
    - Calls `youtube.videos().list(part="status,contentDetails", id=video_id)`
    - Costs 1 quota unit. Increment quota_used.
    - Checks:
      1. status.privacyStatus == "public"
      2. status.uploadStatus == "processed"
      3. status.embeddable == True (warn but don't reject if not embeddable; we download, not embed)
    - Actually, for our use case (downloading via yt-dlp), we only need the video to be public and not deleted. Embeddable doesn't matter for download.
    - Return True if public and uploadStatus == "processed"
    - Log: "Video {video_id}: privacy={status}, upload={upload_status}"

    **Method: find_vods_for_match(match_data: dict) -> dict[int, str | None]**
    - Takes match_data dict (from VLRMatchScraper.parse_match output)
    - For each map in match_data["maps"]:
      1. First check if map already has a vod_url from VLR.gg page
      2. If yes, validate it via validate_video (extract video_id from URL)
      3. If no VLR.gg URL or VLR URL is invalid, search via find_map_vod
    - Returns dict mapping map_number -> youtube_url (or None if not found)
    - Log summary: "Match {teams[0]} vs {teams[1]}: {found}/{total} maps with VODs"

    **Property: quota_remaining -> int**
    - Returns QUOTA_LIMIT - quota_used

    **Custom exception: QuotaExhaustedError(Exception)**
    - Raised when daily quota would be exceeded
    - Message includes quota_used and QUOTA_LIMIT

    **Helper: extract_video_id(url: str) -> str | None**
    - Parses YouTube URLs: youtube.com/watch?v=ID, youtu.be/ID, youtube.com/embed/ID
    - Returns video ID string or None if not a valid YouTube URL

    **Tests** (`tests/scraping/test_youtube_vod_finder.py`):
    - Mock `googleapiclient.discovery.build` throughout (never make real API calls)
    - Test find_map_vod constructs correct search query
    - Test find_map_vod returns URL for accessible video
    - Test find_map_vod returns None when no results
    - Test find_map_vod returns None when all videos are private/deleted
    - Test validate_video returns True for public/processed video
    - Test validate_video returns False for private video
    - Test quota tracking increments correctly (100 for search, 1 for validate)
    - Test QuotaExhaustedError raised when quota would be exceeded
    - Test extract_video_id parses various YouTube URL formats
    - Test find_vods_for_match prefers VLR.gg URLs over search (when VLR URL is valid)
    - Test find_vods_for_match falls back to search when VLR URL is None

    **Important notes:**
    - google-api-python-client is synchronous. This class is sync. Plan 04 will call it from async code via asyncio.to_thread() if needed.
    - All tests must mock the YouTube API. No real API calls.
