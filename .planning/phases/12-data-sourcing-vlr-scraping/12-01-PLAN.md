    1. Extend VODRecord in `src/pipeline/manifest.py` with new optional fields:
       - player_stats: dict | None = None  # {player_name: {acs: float, kills: int, deaths: int, assists: int, kast_pct: float, adr: float, hs_pct: float, fk: int, fd: int}} per map
       - agent_compositions: list[dict] | None = None  # [{name: str, team: str, agent: str}] per map (from Valoscribe scrape_match)
       - player_vlr_ids: dict[str, int] | None = None  # {player_name: vlr_player_id}
       - match_score: str | None = None  # "2-1" format (series score)
       - match_outcome: str | None = None  # "team1_win" or "team2_win" (who won the map)

       These are ALL optional (None default) for backward compatibility with existing empty manifest.
       The to_dict/from_dict round-trip must preserve these fields.

    2. Create `src/scraping/team_normalizer.py`:
       - Class `TeamNormalizer` with:
         - `__init__(self, manual_overrides: dict[str, str] | None = None)` - accepts optional manual mapping dict
         - Default manual_overrides includes common VCT team abbreviations/variants:
           Map both directions: full name <-> abbreviation for teams in Masters Bangkok 2024 and VCT Americas 2024
           Examples: "Gen.G" -> "Gen.G Esports", "T1" -> "T1", "LOUD" -> "LOUD", "Sentinels" -> "Sentinels", "NRG Esports" -> "NRG"
           Keep list small (~15 entries). This is a seed, not exhaustive.
         - `normalize(self, vlr_name: str, known_teams: list[str] | None = None) -> str`:
           1. Check manual_overrides first (exact match) -> return override
           2. If known_teams provided, use RapidFuzz process.extractOne with fuzz.token_sort_ratio
           3. Threshold: score >= 85 -> return match. Below 85 -> log warning, return original vlr_name
           4. If no known_teams -> just check overrides, return vlr_name as-is
         - `extract_player_vlr_id(self, player_link_href: str) -> int | None`:
           Parse "/player/{ID}/{name}" pattern, return int ID or None

    3. Create `tests/scraping/test_team_normalizer.py`:
       - Test exact manual override match
       - Test fuzzy matching with known_teams list (e.g., "Gen.G" matches "Gen.G Esports" at >= 85)
       - Test low-confidence match returns original (e.g., "Cloud9 White" doesn't falsely match "Cloud9")
       - Test extract_player_vlr_id with valid "/player/12345/tenz" -> 12345
       - Test extract_player_vlr_id with invalid path -> None

    4. Create `tests/pipeline/test_manifest_extended.py`:

       - Test that empty manifest.json loads without error (current state: `{"records": []}`)
