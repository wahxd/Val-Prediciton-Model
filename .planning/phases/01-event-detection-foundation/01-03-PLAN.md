**src/events/emitter.py:**

Create class `EventEmitter`:

**Constructor:**
- `self.recent_events: deque[BaseEvent] = deque(maxlen=20)` (tracks recent events for win condition inference)
- `self.current_round_events: list[BaseEvent] = []` (events in current round, cleared on round_start)
- `self.last_spike_state: bool = False` (track previous spike_planted for transition detection)

**Core Method:**

`emit_events(changes: dict[str, tuple[Any, Any]], current_state: GameState, previous_state: GameState) -> list[BaseEvent]`:

Takes the changes dict from StateTracker.detect_changes(), plus current and previous GameState. Returns a list of events to emit. Logic:

1. **Build base_data dict** from current_state for event construction: timestamp, frame_number, game_time (timer), game_time_seconds (converted), score_left, score_right, alive_left, alive_right, spike_planted.

2. **Check for round start** (EVNT-06): If alive_left and alive_right both changed to 5, AND timer changed to a high value (>= 80 seconds = 1:20), emit RoundStartEvent with round_number = score_left + score_right + 1. Clear current_round_events. Reset last_spike_state to False.

3. **Check for kills** (EVNT-02): If alive_left decreased (new < old), emit KillEvent with team="left", alive_before=old, alive_after=new. If alive_right decreased, emit KillEvent with team="right". Note: if alive decreased by more than 1 (e.g., multi-kill between frames), emit one KillEvent with the before/after counts (not multiple single-kill events, since we can't distinguish at team-level granularity).

4. **Check for spike transitions** (EVNT-03, EVNT-04, EVNT-05):
   - If spike_planted changed from False to True: emit SpikePlantEvent with plant_time_seconds from timer.
   - If spike_planted changed from True to False: need to distinguish defuse vs detonate.
     - Check if the round just ended (score changed in same frame or recent events): if winner is the defending team (right team if they were defending), it's a defuse. If winner is attacking team, it's a detonate.
     - Heuristic: if alive counts suggest elimination happened simultaneously, lean toward detonate. If alive_left > 0 and alive_right > 0, lean toward defuse.
     - Fallback: if timer > 0 when spike un-plants, it's a defuse (spike detonation happens at timer ~0:00). If timer is near 0 (< 5 seconds), it's a detonate.
     - Emit SpikeDefuseEvent or SpikeDetonateEvent accordingly.

5. **Check for round end** (EVNT-01): If score_left or score_right increased, emit RoundEndEvent. Determine winner (whichever score increased). Infer win_condition from current_round_events:
   - If SpikeDetonateEvent in current_round_events -> "spike_detonate"
   - If SpikeDefuseEvent in current_round_events -> "spike_defuse"
   - If any team has 0 alive -> "elimination"
   - Else -> "timeout" (timer ran out)
   - Set final_score_left and final_score_right from current_state.

6. **Track state:** Update last_spike_state. Append all emitted events to recent_events and current_round_events.

**Helper Methods:**

`_build_base_data(state: GameState) -> dict`: Extract common event fields from GameState.

`_infer_win_condition(current_round_events: list[BaseEvent], current_state: GameState) -> str`: Determine win condition from round event history.

`reset()`: Clear recent_events, current_round_events, last_spike_state (for new match).

Import from src.events.schemas (all event types) and src.state.models (GameState). Import from src.quality.replay_detector (timer_str_to_seconds) for timer conversion.

**src/quality/metrics.py:**

First, configure structlog at module level for JSON-formatted structured logging:
```python
import structlog
structlog.configure(
    processors=[
        structlog.stdlib.add_log_level,
        structlog.processors.TimeStamper(fmt="iso"),
        structlog.processors.JSONRenderer()
    ],
    context_class=dict,
    logger_factory=structlog.PrintLoggerFactory(),
    cache_logger_on_first_use=True,
)
```

Create class `QualityMetrics`:

**Constructor:**
- `self.logger = structlog.get_logger("quality_metrics")`
- `self.total_frames: int = 0`
- `self.consecutive_failures: int = 0`
- `self.ocr_confidence_sum: dict[str, float]` initialized with keys: timer, score_left, score_right, alive_left, alive_right (all 0.0)
- `self.ocr_confidence_count: dict[str, int]` same keys, all 0
- `self.frames_with_valid_ocr: int = 0`
- `self.frames_skipped_low_confidence: int = 0`
- `self.frames_skipped_invalid_value: int = 0`
- `self.debounce_rejects: int = 0` (frames where value changed but didn't reach 3-frame consensus)
- `self.replay_detections: int = 0`
- `self.replay_frames_suppressed: int = 0`
- `self.events_emitted: dict[str, int]` = defaultdict(int) (count per event_type)
- `self.validation_warnings: list[str]` = [] (coherence violation log)

**Methods:**

`log_ocr_result(field: str, confidence: float, is_valid: bool) -> None`:
Track OCR quality per field. If valid and confidence >= 0.7: add to sum/count, reset consecutive_failures. If invalid: increment consecutive_failures, increment frames_skipped_low_confidence or frames_skipped_invalid_value as appropriate.
- At 10+ consecutive failures (user decision): log WARNING via structlog with field name and failure count.
- At 50+ consecutive failures (user decision: console warning for significant issues): also print to console.
- At 180+ consecutive failures (user decision: 30+ seconds at 6fps): log ERROR with recommendation to check ROI alignment or stream quality.

`log_frame_processed(valid: bool) -> None`: Increment total_frames. If valid, increment frames_with_valid_ocr.

`log_debounce_reject() -> None`: Increment debounce_rejects.

`log_replay_detected(timer_regression: str, current_score: tuple[int, int]) -> None`: Increment replay_detections. Log info via structlog with timer and score context.

`log_replay_frame_suppressed() -> None`: Increment replay_frames_suppressed.

`log_event_emitted(event_type: str) -> None`: Increment events_emitted[event_type]. Log debug via structlog.

`log_validation_warning(warning: str) -> None`: Append to validation_warnings. Log warning via structlog.

`get_summary() -> dict`: Return comprehensive metrics summary for post-stream analysis:
```python
{
    "total_frames": int,
    "frames_with_valid_ocr": int,
    "frames_skipped_low_confidence": int,
    "frames_skipped_invalid_value": int,
    "ocr_success_rate": float,  # frames_with_valid_ocr / total_frames
    "avg_confidence": {field: avg for each field},
    "debounce_rejects": int,
    "replay_detections": int,
    "replay_frames_suppressed": int,
    "events_emitted": dict,
    "total_events": int,
    "validation_warnings_count": int,
}
```

`reset() -> None`: Reset all counters (for new match).

Per user decisions:
- Console warnings for significant issues (50+ consecutive frame failures)
- Full details to log file (via structlog JSON output)
- Track per-field OCR confidence for post-stream analysis
- Track debounce statistics and replay detection triggers
