**src/quality/replay_detector.py:**

Create class `ReplayDetector`:

**Internal state (use a simple dataclass or named attributes):**
- `is_suppressed: bool = False` (currently in replay suppression mode)
- `regression_timer_sec: Optional[int] = None` (timer value in seconds when regression was detected)
- `last_live_score: tuple[int, int] = (0, 0)` (score at time of entering replay)
- `suppression_start_frame: Optional[int] = None` (frame number when suppression started, for metrics)
- `frames_suppressed: int = 0` (total frames suppressed across all replays, for metrics)
- `replay_count: int = 0` (number of replay segments detected, for metrics)

**Methods:**

`check_frame(current_timer_sec: Optional[int], current_score: tuple[int, int], previous_timer_sec: Optional[int], previous_score: tuple[int, int], frame_number: int) -> bool`:
Returns True if events should be suppressed (replay detected or ongoing).

Logic (per user decision - both conditions required):
1. If either timer is None (invalid OCR), maintain current suppression state (don't change mode on bad data).
2. **Detect NEW replay:** `current_timer_sec > previous_timer_sec` (timer went backwards = regression) AND `current_score == previous_score` (score didn't change = not a new round). If detected: set is_suppressed=True, store regression_timer_sec=previous_timer_sec, increment replay_count, store suppression_start_frame.
3. **While suppressed:** Check exit condition: `current_timer_sec < regression_timer_sec` (timer has progressed forward past the point where regression was detected). If exit condition met: set is_suppressed=False, clear regression_timer_sec.
4. **While suppressed:** Also exit if score changes (new round started during replay viewing): `current_score != last_live_score`.
5. If suppressed, increment frames_suppressed.
6. Return is_suppressed.

`reset()`: Clear all state (used at match start).

`get_metrics() -> dict`: Return dict with replay_count, frames_suppressed, is_currently_suppressed.

**Important edge cases to handle:**
- Timer going from "0:05" to "1:40" is a new round (score should have changed), NOT a replay. The score check prevents this false positive.
- Multiple consecutive replays: each enters and exits independently.
- Timer OCR failure during replay: maintain suppression state (don't exit on bad data).

Add a module-level helper function `timer_str_to_seconds(timer: str) -> Optional[int]` that converts "M:SS" or "MM:SS" to integer seconds. Returns None if format is invalid. This is shared utility used by both ReplayDetector and the StateTracker.
