**src/state/tracker.py:**
Create class `StateTracker`:
- `__init__`: Initialize `self.history: deque[GameState] = deque(maxlen=3)` and `self.confirmed_state: Optional[GameState] = None`
- `update(state: GameState) -> None`: Append state to history ring buffer
- `has_consensus(field: str) -> bool`: Return True only if all 3 frames in history have identical value for the given field. Return False if fewer than 3 frames.
- `get_stable_fields() -> dict[str, Any]`: Return dict of field->value for all tracked fields (score_left, score_right, alive_left, alive_right, timer, spike_planted) that have 3-frame consensus. Empty dict if < 3 frames.
- `detect_changes() -> dict[str, tuple[Any, Any]]`: Compare current stable fields against `self.confirmed_state`. Return dict of field->(old_value, new_value) for changed fields. If no confirmed state yet, return empty dict. When stable fields are detected, update `self.confirmed_state` to a new GameState from the latest history entry (using only the stable field values).
- `reset()`: Clear history and confirmed_state (used at round boundaries)

Import GameState from models. Use `collections.deque` for the ring buffer (not a list).

  <files>src/state/validator.py</files>
  <action>
**src/state/validator.py:**
Create class `StateValidator`:

**Constructor:**
- `self.min_ocr_confidence: float = 0.7` (per user decision: 70% minimum)
- `self.last_valid_state: Optional[GameState] = None` (tracks last accepted state for coherence checks)
- `self.in_round: bool = False` (tracks whether we're mid-round for coherence rules)
- `self.consecutive_failures: int = 0` (tracks consecutive validation failures)
- `self.failure_threshold_warn: int = 10` (per user decision: warn at 10+ consecutive failures)
- `self.failure_threshold_pause: int = 180` (per user decision: 30 seconds at 6fps = 180 frames)

**Methods:**

`validate_frame(raw_state: dict, ocr_confidence: dict[str, float]) -> Optional[GameState]`:
Main entry point. Takes raw extracted values (from VCTVisionEngine output) and per-field OCR confidence scores. Returns a valid GameState or None if frame should be skipped.
1. Check each field's OCR confidence against 0.7 threshold. Skip field if below (use last known value or None).
2. Validate ranges: alive_left/right in [0,5], score_left/right in [0,13], timer matches `^\d{1,2}:\d{2}$`
3. If ANY critical field (score, alive, timer) is invalid, increment consecutive_failures and return None
4. If valid, reset consecutive_failures to 0
5. Construct and return GameState

`check_coherence(new_state: GameState) -> tuple[bool, list[str]]`:
Validates state transitions against game logic. Returns (is_coherent, list_of_warnings).
- QUAL-02: If `in_round` is True, alive counts must not increase (alive_left <= last_valid.alive_left, same for right). Exception: if score changed (new round started), allow reset.
- QUAL-03: Score must not decrease within a match half (score_left >= last_valid.score_left, same for right).
- Detect round start: if alive counts both return to 5 and timer resets high (> 1:30), set in_round = True and update round tracking.

`should_warn() -> bool`: Returns True if consecutive_failures >= failure_threshold_warn (10).

`should_pause() -> bool`: Returns True if consecutive_failures >= failure_threshold_pause (180).

`mark_round_start()`: Reset in_round tracking, update last_valid_state alive counts to 5.

`mark_round_end()`: Set in_round = False.

Per user decision: invalid values are discarded and frame is skipped (return None), NOT auto-corrected.
  </action>
