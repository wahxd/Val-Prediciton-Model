**Test cases for EventEmitter:**

1. `test_kill_event_on_alive_decrease`: alive_left changes 4 -> 3, everything else same -> emits 1 KillEvent with team="left", alive_before=4, alive_after=3.

2. `test_kill_event_right_team`: alive_right changes 5 -> 4 -> emits KillEvent with team="right".

3. `test_double_kill_same_frame`: alive_left changes 4 -> 2 -> emits 1 KillEvent (not 2, since we can't distinguish individual kills at team level).

4. `test_round_end_on_score_increase_left`: score_left changes 5 -> 6, alive_right=0 -> emits RoundEndEvent with winner="left", win_condition="elimination".

5. `test_round_end_on_score_increase_right`: score_right changes 3 -> 4 -> emits RoundEndEvent with winner="right".

6. `test_spike_plant_event`: spike_planted changes False -> True, timer="1:05" -> emits SpikePlantEvent with plant_time_seconds=65.

7. `test_spike_defuse_event`: spike_planted changes True -> False, timer > 0, both teams alive -> emits SpikeDefuseEvent.

8. `test_round_start_requires_timer_transition_not_just_threshold`: Two frames both with timer >= 80 seconds (e.g., "1:25" -> "1:23") and alive 5v5 should NOT emit RoundStartEvent (no transition from low to high). This explicitly tests that the threshold-only approach was replaced with transition detection.

9. `test_round_start_on_timer_transition_low_to_high`: previous timer "0:05" (5 seconds), current timer "1:40" (100 seconds), alive 5v5 -> DOES emit RoundStartEvent. This is the correct transition-based detection.

10. `test_round_start_transition_without_5v5_does_not_trigger`: Timer transitions low to high but alive counts are NOT 5v5 (e.g., 3v4) -> should NOT emit RoundStartEvent.

11. `test_timeout_event_emitted_on_timer_freeze`: Simulate timer frozen at same value for 5+ consecutive frames mid-round (alive > 0 both sides) -> emits TimeoutEvent with team attribution.

12. `test_timeout_event_team_attribution_fewer_alive`: Timer freezes when left has 2 alive, right has 4 -> TimeoutEvent.team should be "left" (fewer alive = likely called timeout).

13. `test_timeout_event_not_emitted_between_rounds`: Timer frozen but alive counts are 0 on one side (round is over) -> should NOT emit TimeoutEvent.

14. `test_events_include_full_state_snapshot`: Any emitted event has score_left, score_right, alive_left, alive_right, spike_planted, game_time fields populated from current_state.

15. `test_no_events_on_no_changes`: Empty changes dict -> returns empty list.

16. `test_multiple_events_same_frame`: alive_left decreases AND score increases in same frame -> emits both KillEvent and RoundEndEvent.

17. `test_reset_clears_round_events`: Emit some events, reset(), check internal state is clean.
