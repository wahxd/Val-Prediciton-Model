Create `tests/` package with `__init__.py`.

**tests/test_state_tracker.py:**

Create a helper function `make_state(**overrides) -> GameState` that returns a GameState with sensible defaults (score 5-3, alive 5-5, timer "1:30", spike False, frame_number auto-incrementing, timestamp auto-incrementing, ocr_confidence all 0.9) and allows overriding any field.

**Test cases for StateTracker:**

1. `test_empty_tracker_returns_no_stable_fields`: New StateTracker with 0 frames -> get_stable_fields() returns empty dict.

2. `test_one_frame_returns_no_stable_fields`: Add 1 frame -> get_stable_fields() returns empty dict (need 3 for consensus).

3. `test_two_frames_returns_no_stable_fields`: Add 2 identical frames -> still empty dict.

4. `test_three_identical_frames_returns_all_stable`: Add 3 frames with identical values -> get_stable_fields() returns all 6 tracked fields with correct values.

5. `test_three_frames_with_one_different_field_excludes_it`: Add 3 frames where alive_left is 5, 4, 4 -> get_stable_fields() should NOT include alive_left (no consensus), but SHOULD include other unchanged fields.

6. `test_detect_changes_returns_diffs`: Set confirmed_state, then add 3 frames with new score -> detect_changes() returns {'score_right': (3, 4)}.

7. `test_detect_changes_empty_when_no_change`: Set confirmed_state, add 3 identical frames matching confirmed -> detect_changes() returns empty dict.

8. `test_ring_buffer_evicts_oldest`: Add 4 frames (first has alive_left=5, next 3 have alive_left=4) -> get_stable_fields() includes alive_left=4 (oldest frame evicted).

9. `test_reset_clears_everything`: Add frames, reset(), get_stable_fields() returns empty dict.

**tests/test_validator.py:**

**Test cases for StateValidator:**

1. `test_valid_frame_passes`: All fields valid, all confidence >= 0.7 -> returns GameState.

2. `test_low_confidence_timer_rejects_frame`: timer confidence 0.5 -> returns None.

3. `test_low_confidence_score_rejects_frame`: score_left confidence 0.6 -> returns None.

4. `test_alive_count_above_5_rejects`: alive_left=6 -> returns None.

5. `test_alive_count_negative_rejects`: alive_left=-1 -> returns None.

6. `test_score_above_13_rejects`: score_left=14 -> returns None.

7. `test_malformed_timer_rejects`: timer="abc" -> returns None.

8. `test_coherence_alive_increase_mid_round_warns`: Set in_round=True with last alive_left=3, then check coherence with alive_left=4 -> returns (False, [warning]).

9. `test_coherence_score_decrease_warns`: last score_left=5, new score_left=4 -> returns (False, [warning]).

10. `test_coherence_round_start_allows_alive_reset`: After round end, alive going from 2 to 5 is OK (new round).

11. `test_consecutive_failures_tracking`: Submit 11 invalid frames -> should_warn() returns True after 10.

12. `test_consecutive_failures_reset_on_valid`: Submit 5 invalid, then 1 valid -> consecutive_failures resets to 0.

Use `pytest` conventions. Each test function is independent.

**tests/test_replay_detector.py:**

**Test cases for ReplayDetector:**

1. `test_normal_play_not_suppressed`: Timer counting down (90 -> 89 -> 88), score unchanged -> all return False.

2. `test_timer_regression_with_same_score_triggers_replay`: Timer goes 30 -> 85 (regression), score unchanged -> returns True.

3. `test_timer_regression_with_score_change_not_replay`: Timer goes 5 -> 100 (new round reset), score changes (5,3) -> (6,3) -> returns False (new round, not replay).

4. `test_replay_suppression_continues_until_exit`: Enter replay (timer regression), subsequent frames with timer still above regression point -> all return True.

5. `test_replay_exits_when_timer_passes_regression_point`: Enter replay at timer=30 (regression from 30 to 85). Subsequent frames: timer goes 85, 80, 70, 25 -> frame at 25 should return False (passed regression point of 30).

6. `test_replay_exits_on_score_change`: Enter replay, then score changes -> should exit suppression.

7. `test_invalid_timer_maintains_current_state`: During normal play, None timer -> returns False (maintains non-suppressed). During replay, None timer -> returns True (maintains suppressed).

8. `test_multiple_replays_tracked_independently`: First replay enters and exits. Second replay triggers -> replay_count is 2.

9. `test_metrics_track_replay_count_and_suppressed_frames`: Trigger replay, check 5 frames during replay -> get_metrics() shows replay_count=1, frames_suppressed=5.

10. `test_reset_clears_state`: Enter replay, reset(), check normal frame -> returns False.

**tests/test_event_emitter.py:**

Create helper `make_state(**overrides) -> GameState` (same pattern as tracker tests).

**Test cases for EventEmitter:**

1. `test_kill_event_on_alive_decrease`: alive_left changes 4 -> 3, everything else same -> emits 1 KillEvent with team="left", alive_before=4, alive_after=3.

2. `test_kill_event_right_team`: alive_right changes 5 -> 4 -> emits KillEvent with team="right".

3. `test_double_kill_same_frame`: alive_left changes 4 -> 2 -> emits 1 KillEvent (not 2, since we can't distinguish individual kills at team level).

4. `test_round_end_on_score_increase_left`: score_left changes 5 -> 6, alive_right=0 -> emits RoundEndEvent with winner="left", win_condition="elimination".

5. `test_round_end_on_score_increase_right`: score_right changes 3 -> 4 -> emits RoundEndEvent with winner="right".

6. `test_spike_plant_event`: spike_planted changes False -> True, timer="1:05" -> emits SpikePlantEvent with plant_time_seconds=65.

7. `test_spike_defuse_event`: spike_planted changes True -> False, timer > 0, both teams alive -> emits SpikeDefuseEvent.

8. `test_round_start_event`: alive_left and alive_right both change to 5, timer changes to high value (>= 1:20) -> emits RoundStartEvent with round_number = score_left + score_right + 1.

9. `test_events_include_full_state_snapshot`: Any emitted event has score_left, score_right, alive_left, alive_right, spike_planted, game_time fields populated from current_state.

10. `test_no_events_on_no_changes`: Empty changes dict -> returns empty list.

11. `test_multiple_events_same_frame`: alive_left decreases AND score increases in same frame -> emits both KillEvent and RoundEndEvent.

12. `test_reset_clears_round_events`: Emit some events, reset(), check internal state is clean.

Use `pytest` conventions. Import from src.events.emitter, src.events.schemas, src.state.models.
