       - Class `DataPipelineConfig` with fields:

         - `audit_output_dir: Path = Path("data/audit")`
         - `log_level: str = "INFO"`
       - Config: `env_file=".env"`, `env_file_encoding="utf-8"`, NO prefix (use bare `VALOSCRIBE_DATA_DIR` as the env var name, matching the user's decision in CONTEXT.md)

       - Add a helper function `get_config(data_dir_override: Path | None = None) -> DataPipelineConfig` that creates config with optional override

    2. Create `src/data/schemas.py`:
       - All models use `model_config = ConfigDict(extra='allow')` to preserve unknown fields during discovery phase
       - Base class `ValoscribeEvent(BaseModel)` with: type (str), timestamp (float), round (int). Add `model_config` with `extra='allow'`.
       - Subclasses (all inherit from ValoscribeEvent):
         - `KillEvent` -- type: Literal["kill"], killer: str, victim: str, weapon: str, killer_team: str, victim_team: str
         - `RoundStartEvent` -- type: Literal["round_start"]
         - `RoundEndEvent` -- type: Literal["round_end"], winning_team: str, score_team1: int, score_team2: int
         - `SpikePlantEvent` -- type: Literal["spike_plant"]
         - `SpikeDefuseEvent` -- type: Literal["spike_defuse"]
       - `MapMetadata(BaseModel)` with extra='allow': teams (list[str]), map_name (str), date (str), agents (dict[str, Any] = {}), validation_results (dict[str, Any] = {}). All optional fields have defaults so partial metadata still parses.
       - Function `parse_event(raw_json: str) -> ValoscribeEvent`: Parses a raw JSON string. First parse as base `ValoscribeEvent` to get the type field, then dispatch to the specific subclass based on type. If type is unknown, return the base `ValoscribeEvent` (preserving all fields via extra='allow'). Use `model_validate_json()` for efficiency.
       - A dict `EVENT_TYPE_MAP: dict[str, type[ValoscribeEvent]]` mapping type strings to subclasses (e.g., "kill" -> KillEvent)

    3. Create `tests/data/test_schemas.py`:
       Tests (using pytest):
       - `test_parse_kill_event` -- parse a kill event JSON, verify all fields populated
       - `test_parse_round_end_event` -- parse round_end, verify scores and winning_team
       - `test_parse_unknown_event_type` -- parse an event with type="ability_use" (not in EVENT_TYPE_MAP), verify it returns base ValoscribeEvent with all fields preserved
       - `test_extra_fields_preserved` -- parse a kill event with an extra field like "headshot": true, verify the extra field is accessible via `event.model_extra`
       - `test_invalid_event_raises` -- parse garbage JSON, verify ValidationError raised
       - `test_map_metadata_parse` -- parse sample_metadata.json fixture, verify fields
       - `test_map_metadata_partial` -- parse metadata missing optional fields (no agents, no validation_results), verify it still parses with defaults
       - `test_config_loads_from_env` -- use monkeypatch to set VALOSCRIBE_DATA_DIR env var, verify DataPipelineConfig loads it
       - `test_config_override` -- verify get_config(data_dir_override=...) overrides env var
