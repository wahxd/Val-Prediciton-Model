  <name>Task 1: Data loader -- map discovery, per-map loading, batch loading with error collection</name>
  <files>src/data/loader.py</files>
  <action>
    Create `src/data/loader.py` with the following components:

    **Data classes:**
    - `MapData` (dataclass or Pydantic model):
      - `map_id: str` (directory name)
      - `map_dir: Path`
      - `events: list[ValoscribeEvent]` (parsed JSONL events)
      - `frames: pd.DataFrame | None` (parsed CSV frames, None if file missing)
      - `metadata: MapMetadata | None` (parsed JSON metadata, None if file missing)
      - `files_found: list[str]` (which files were present: "events.jsonl", "frames.csv", "metadata.json")
      - `event_count: int` (len of events)
      - `parse_errors: list[dict]` (per-line JSONL parse errors with line number and error detail)

    - `LoadResult` (dataclass):
      - `map_id: str`
      - `success: bool`
      - `data: MapData | None` (None if failed)
      - `error: str | None` (error message if failed)
      - `error_phase: str | None` ("discovery", "events", "frames", "metadata")

    **Functions:**

    1. `discover_maps(data_dir: Path) -> dict[str, Path]`:
       - Scan `data_dir` for subdirectories (each subdirectory is a map)
       - Return dict of {map_id: map_dir_path}
       - Sort by directory name for deterministic ordering
       - If data_dir doesn't exist, raise FileNotFoundError with clear message including the path

    2. `load_events(events_file: Path) -> tuple[list[ValoscribeEvent], list[dict]]`:
       - Parse JSONL line-by-line using `parse_event()` from schemas
       - Return (events, parse_errors) -- continue on per-line errors
       - Each error dict: {"line": int, "error": str, "raw": str (truncated to 200 chars)}
       - Use structlog for warning on parse errors

    3. `load_frames(frames_file: Path) -> pd.DataFrame`:
       - Use `pd.read_csv()` with engine='pyarrow' if available, fall back to default
       - Return the DataFrame as-is (discovery phase -- don't assume columns)

    4. `load_metadata(metadata_file: Path) -> MapMetadata`:
       - Load JSON, parse with `MapMetadata.model_validate()`
       - Preserves extra fields via extra='allow'

    5. `load_map(map_dir: Path) -> MapData`:
       - Check which files exist: events.jsonl, frames.csv, metadata.json
       - Load each file that exists (skip missing ones, record in files_found)
       - At minimum, events.jsonl must exist -- raise ValueError if missing
       - Return MapData with all loaded data

    6. `load_all_maps(data_dir: Path, map_ids: list[str] | None = None) -> dict[str, LoadResult]`:
       - Discover all maps (or filter to map_ids if provided)
       - Load each map with continue-on-error
       - Use structlog to log progress: "Loading map {i}/{total}: {map_id}"
       - Return dict of {map_id: LoadResult}
       - Log summary at end: "{success_count}/{total} maps loaded, {failure_count} failures"

    7. `get_map_index(results: dict[str, LoadResult]) -> list[dict]`:
       - For each successful LoadResult, extract summary: map_id, teams (from metadata), map_name (from metadata), date (from metadata), event_count, files_found
       - Return list of dicts sorted by map_id
       - Handle missing metadata gracefully (use "unknown" for missing fields)

    **Important implementation notes:**
    - Use `pathlib.Path` throughout, NEVER string concatenation for paths
    - Use structlog for all logging (already in project from Phase 1)
    - All functions should work independently (load_events doesn't need config)
    - The Python API is the core -- CLI wraps this, Phase 8+ imports this directly
