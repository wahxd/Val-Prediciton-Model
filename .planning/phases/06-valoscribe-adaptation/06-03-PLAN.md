    2. Create `src/valoscribe/output/output_adapter.py`:
       - Follow Valoscribe conventions (`from __future__ import annotations`, Google docstrings)
       - Class `OutputAdapter`:
         ```python
         class OutputAdapter:
             """Adapts internal event representations to output format.

             Provides a clean boundary between extraction logic and output
             formatting. Handles all event types (existing and new).
             """

             def adapt_event(self, event: Any) -> dict:
                 """Convert internal event to JSONL-serializable dict.

                 Args:
                     event: Internal event object with type, timestamp, round attributes

                 Returns:
                     Dictionary ready for JSON serialization
                 """
         ```
       - `adapt_event()` must handle ALL event types:
         - **Existing types** (preserve exactly as-is for backward compatibility):
           - `kill`: type, timestamp, round, killer, victim, weapon, killer_team, victim_team
           - `round_start`: type, timestamp, round + NEW: sides dict
           - `round_end`: type, timestamp, round, winning_team, score_team1, score_team2 + NEW: sides dict
           - `spike_plant`: type, timestamp, round
           - `spike_defuse`: type, timestamp, round
         - **New types** (from Plan 02):
           - `buy_phase`: type, timestamp, round, team1_credits, team2_credits, team1_loadout_type, team2_loadout_type
           - `ult_usage`: type, timestamp, round, player, agent, ult_name (or player_index, agent)
           - `timeout`: type, timestamp, round, team
         - Use `hasattr()` checks for new fields on existing events (sides on round_start/round_end) to maintain backward compatibility
         - Any event type not explicitly handled: serialize all attributes as a dict (fallback for future extensibility)

       - `write_events_jsonl(events: list, output_path: Path) -> None`:
         - Writes all events to a JSONL file using adapt_event()
         - One JSON object per line, UTF-8 encoding

       - `write_frames_csv(frames_data: Any, output_path: Path) -> None`:
         - Delegates to pandas DataFrame.to_csv() if frames are a DataFrame
         - Ensures consistent CSV column ordering

    **CRITICAL: Output file naming alignment:**
    Valoscribe currently outputs `event_log.jsonl` and `frame_states.csv` in an `output/` subdirectory per map. Phase 5 loaders expect `events.jsonl` and `frames.csv` directly in the map directory.

    The OutputAdapter should use the filenames: `events.jsonl`, `frames.csv`, `metadata.json` (matching what Phase 5 loaders expect). This is safe because all 71 maps will be reprocessed -- there's no need to maintain the old naming.
