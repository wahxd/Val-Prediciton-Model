         - Use OCR on the top-center region (same area as timer/round info) to detect timeout text
         - Implementation approach (concrete, not a stub):
           ```python
           class TimeoutDetector:
               """Detect tactical timeout events from HUD text overlay."""

               def __init__(self, cropper: Cropper, ocr_engine: OCREngine):
                   self.cropper = cropper
                   self.ocr = ocr_engine
                   self._last_timeout_detected: bool = False

               def detect_timeout(self, frame: np.ndarray) -> Optional[TimeoutInfo]:
                   """Detect timeout by OCR-ing top-center HUD for 'TIMEOUT' text.

                   Uses the timer/round region which is repurposed during timeouts
                   to display timeout text overlay.
                   """
                   # Crop the top-center region (timer area, repurposed during timeout)
                   region = self.cropper.crop_simple_region(frame, "round_number")
                   if region is None:
                       return None

                   # OCR the region and check for timeout text
                   text = self.ocr.extract_text(region).upper().strip()

                   if "TIMEOUT" in text:
                       if not self._last_timeout_detected:
                           self._last_timeout_detected = True
                           # Parse team name from surrounding text if possible,
                           # otherwise return "unknown" (enriched later from round context)
                           team = self._parse_team_from_text(text)
                           return TimeoutInfo(team=team, detected=True)
                   else:
                       self._last_timeout_detected = False

                   return None

               def _parse_team_from_text(self, text: str) -> str:
                   """Extract team name from timeout text overlay.

                   VCT broadcasts show 'TEAM_NAME TIMEOUT'. Extract the team
                   name prefix. If parsing fails, return 'unknown'.
                   """
                   # Text is like "TEAM_NAME TIMEOUT" or "TIMEOUT CALLED BY TEAM_NAME"
                   parts = text.replace("TIMEOUT", "").strip()
                   return parts if parts else "unknown"
           ```
         - The `_last_timeout_detected` flag ensures we emit only ONE timeout event per timeout (not one per frame)
         - The `round_number` crop region is reused because VCT broadcasts overlay timeout text in the same top-center HUD area where the round number normally appears
         - If OCR reads "TIMEOUT" in that region, a timeout is active
         - Return TimeoutInfo with team name, or None if no timeout detected

       class RoundManager:
           def __init__(self, metadata: dict):
               # ... existing init ...

               # Extract starting sides from VLR metadata
               # VLR scraper provides: metadata["sides"] = {"Team A": "attack", "Team B": "defense"}
               self.starting_sides: dict[str, str] = metadata.get("sides", {})

       If `metadata["sides"]` is missing (e.g., scraper failure), `get_current_sides()` returns an empty dict -- downstream code treats empty sides as "unknown" rather than crashing. This is a safe degradation path.

       - Add `get_current_sides(round_number: int) -> dict[str, str]` method:
         ```python
         def get_current_sides(self, round_number: int) -> dict[str, str]:
             """Get attacker/defender assignment for each team.

             Valorant side logic:
             - Rounds 1-12: First half (starting sides)
             - Rounds 13-24: Second half (swapped)
             - Rounds 25+: Overtime (swap every 2 rounds)

             Returns empty dict if starting_sides was not provided in VLR metadata.
             """
             if not self.starting_sides:
                 return {}
             if round_number <= 12:
                 return dict(self.starting_sides)
             elif round_number <= 24:
                 return self._swap_sides(self.starting_sides)
             else:
                 ot_round = round_number - 24
                 swaps = (ot_round - 1) // 2
                 if swaps % 2 == 0:
                     return self._swap_sides(self.starting_sides)
                 else:
                     return dict(self.starting_sides)
         ```
       - Add `_swap_sides()` helper method
